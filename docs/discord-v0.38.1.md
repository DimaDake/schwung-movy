## Movy v0.38.1, and a pause

Two fixes, both from the community:
- **4K EQ no longer restarts Schwung** when it goes on a track or the master. Thanks dbdefault!
- **A synth on USB-A goes quiet when Movy closes.** Before, a note that was sounding kept hanging on the external synth. Thanks **ldap**!

Update from the Module Store, or with the one-command install: https://dimadake.github.io/schwung-movy/install/

**Movy is going on pause after this release.** For personal reasons I can't keep working on it, so there won't be new features for a while, and I'm not reviewing feature pull requests. v0.38.1 stays in the store and keeps working with the Schwung it was built for. If something is really broken I may still fix it, but I can't promise when.

Movy is MIT licensed. If you want to take it further, fork it, and tell me so I can link your fork from the README. Thanks to everyone who played with it, reported bugs and sent code. Maybe I'll be back one day.
