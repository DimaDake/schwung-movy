# About

Movy is made by **megadake** and contributors, and is released under the
[MIT licence](https://github.com/DimaDake/schwung-movy/blob/main/LICENSE).

## Where it comes from

| | Inspired by |
| --- | --- |
| **Screen and knobs** | [Elektron](https://www.elektron.se/) instruments: parameter pages, parameter locks, trig conditions. |
| **Sequencer** | Ableton **Move**'s own sequencer. Movy aims to feel the same, for 16 tracks of Schwung modules. |
| **Engine** | [Davebox](https://github.com/legsmechanical/schwung-davebox)'s engine and transport approach. |
| **Platform** | [Schwung](https://github.com/charlesvestal/schwung), which makes running custom modules on Move possible. |
